# Freebuff-Specific Skills

These skills are specific to Freebuff's plugin and agent system. They are not applicable to Antigravity or other agents.

- **hook-development** — Freebuff hook system (PreToolUse, PostToolUse, Stop, SessionStart)
- **plugin-structure** — Freebuff plugin architecture (.claude-plugin/plugin.json)
- **agent-development** — Freebuff agent frontmatter (model, color, triggering examples)

These are manual-install only. Copy the relevant skill to `.freebuff/skills/` when working in Freebuff.
